# 制表符速查

## 来源

`detail/box_chars.hpp`（库内制表字符定义）与 Unicode Box Drawing 区
（U+2500–U+257F）。ASCII 退化映射由 `Opts::ascii_only()` 控制
（制表符 → '+'、块字符 → '#'）。

## 线型字符

| 字符 | 码点 | 用途 |
| --- | --- | --- |
| ─ │ | U+2500 / U+2502 | 横线 / 竖线 |
| ┌ ┐ └ ┘ | U+250C… | 直角 |
| ├ ┤ ┬ ┴ ┼ | U+251C… | 三通/十字 |
| ═ ║ ╔╗╚╝╠╣╦╩╬ | U+2550… | 双线 |
| ╭ ╮ ╰ ╯ | U+256D… | 圆角 |

## 图形符号（图表常用）

| 字符 | 码点 | 用途 |
| --- | --- | --- |
| • ● ○ | U+2022/25CF/25CB | 连线点 / 实心点 / 空心点 |
| ▲ ▼ ◆ ★ ☆ | — | 变化方向 / 菱形 / 星级 |
| ⣿ 类 | U+2800–U+28FF | 盲文点阵（braille 光栅器，空白是 U+2800 **不是空格**） |
| ░▒▓█ | — | 密度阶梯（扇区/系列专属字符的来源） |

## 使用约定

- 图表靠**专属字符**区分系列/扇区（█▓▒░■●▲◆○ 循环），单色终端可读；
- 半块字符一个 ▀ 表达上下两"像素"（各自前景/背景色）——半块光栅化与
  图片降级（protocol/halfblock_image.hpp）的基元；
- 宽字符（含部分块/图形符号按 wcwidth 判定）占两格，
  生产者负责续接格 `kContinuationCp`（design/utf8_handling.md）。
